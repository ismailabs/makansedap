# MakanSedap V2 skill audit

Audited 19 October 2026. All ten local `.agents/skills/*/SKILL.md` files were read, including frontmatter and execution guidance. Relevant token references and selected helper implementations were inspected; no skill helper was executed and no skill folder was changed. This is an applicability and side-effect review, not a security certification of every bundled script or dataset.

The release contract governs content, privacy, scope and deployment. Skill recommendations cannot change the 51 locked menu entries, introduce fictional business facts, collect booking data, or authorize unrelated changes.

## Conflicts and concrete side effects

- **Content truth wins.** Global `redesign-existing-projects` suggests making sample numbers “organic” and randomizing dates to appear real. Those suggestions are unsuitable here. Preserve exact menu content and avoid invented hours, location, reviews, metrics or service claims. Its useful guidance is scan → diagnose → targeted improvement using the existing stack.
- **Conversion requirements win.** Banner and UI guidance favors one primary CTA. The approved site has two equally important Studio conversion routes. Give them clear, discoverable labels and deliberate placement while keeping restaurant tasks understandable; do not delete a required route to satisfy a template rule.
- **Motion is optional and contextual.** `frontend-design` warns against repeated fade/slide entrances; other skills suggest staggered reveals, inertia, parallax or animated type. Favor restrained user-triggered feedback, readable content from first paint, native scrolling and reduced-motion support. No library is justified by a skill example alone.
- **Do not multiply sources of truth.** `brand` sync writes `assets/design-tokens.json` and regenerates CSS; `design-system` can write an explicit output file; `ui-ux-pro-max --persist` creates `design-system/<project>/MASTER.md` and page overrides. Preserve one reviewed project direction and existing assets instead of running all three generators.
- **Install/generation commands have real effects.** `ui-styling` runs shadcn/Tailwind install paths and its installer can overwrite components when requested. `design` helpers use `GEMINI_API_KEY`, external generation and output writes. These are dormant capabilities, not requirements for this release. Do not run broad `npx ...@latest`, pip setup, credential changes or system installs just because an example shows them.
- **Several paths/tool chains are unavailable in this clone.** `.claude/skills` is absent, as are local `ai-artist`, `ai-multimodal`, `chrome-devtools` and `assets-organizing` skill folders. Older `.claude` commands must not be copied blindly. At audit time, `wrangler.jsonc` existed but Wrangler was absent from `package.json` and local `node_modules`; verify and document the actual pinned release CLI path before deployment.
- **Freshness must be checked at use.** Version strings do not prove script freshness. The shadcn helper has a pinned `2.3.0` fallback while its skill examples use `@latest`; creative examples name specific Gemini models. Current provider syntax, font/assets licensing and performance claims require their own evidence. The local Wrangler and performance skills already prescribe retrieval rather than trusting memorized commands or thresholds.

## Creative guidance retained

Both global creative skills were read. `frontend-design` contributes the stronger governing method: ground the hero in the restaurant's subject, select type deliberately, make a compact palette/type/layout plan, critique it against the brief, concentrate boldness in one memorable treatment, then inspect real screenshots. Its warning that cream/serif/clay and broadsheet treatments can themselves become defaults is useful: luxury editorial styling still needs food-specific composition and content.

`redesign-existing-projects` contributes practical checks for active navigation, visible focus, restrained card use, readable measure, tabular prices, semantic structure, real destinations, mobile viewport behavior and missing error states. Apply these selectively; do not import its placeholder-photo, invented-data, compulsory texture, universal animation or new-page suggestions.

Recommendation for later cleanup: retain all folders now. If the user later requests consolidation, make `design` a routing index rather than an additional execution pipeline, group duplicated slide/banner references under their dedicated owners, and repair obsolete `.claude` paths with tests and backups. No deletion or global-skill change is needed for V2.
