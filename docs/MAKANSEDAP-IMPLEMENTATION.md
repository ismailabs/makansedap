Visual direction: a contemporary Malaysian supper club. Charcoal #141511, botanical #20221b, terracotta #a44d34, ivory #f7efdf and copper #dfaf7a. Self-hosted Cormorant Garamond display and DM Sans body. The board informed image dominance, warm colour, serif hierarchy, rounded controls and restrained framing. The existing food photography is stronger than inventing 51 dish illustrations, so menu entries use consistent text cards with three authentic highlights and category photographs. All 51 names, categories, prices and descriptions remain exact.

Desktop uses a maximum 1280px content width, a photographic hero, three-column menu cards and asymmetric gallery. Below 1100px menu becomes two columns; below 700px it becomes one. At mobile widths the hero photograph leads into readable copy, the navigation collapses with accessible state/Escape behavior, and the gallery uses two columns with periodic wide images. No-JS users retain all menu entries and normal image links. Gallery filters are buttons with pressed state and live announcements; the modal follows visible entries and returns focus. Reservation preview collects no personal information and makes no network request.

Authored sources are styles.css, fonts.css, editorial.css and makansedap.css, compiled in that order. Shared foundation styles remain because they support existing component contracts. Page heads, wordmarks, favicon PNG/SVG, social preview and narrative name meaning are rebranded. Canonicals/social URLs/sitemap use the new domain. The historical handoff and baseline retain old names to preserve provenance.
